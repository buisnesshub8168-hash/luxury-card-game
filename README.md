# Luxury Drive

A simple original luxury car game prototype built with Python and Pygame.

Features:
- Drive a premium sports car through traffic
- Collect luxury gems for score
- Avoid collisions to survive
- Increasing difficulty over time
- Full-screen style UI with responsive controls

## How to run

1. Install Python 3.10+
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Start the game:
   ```bash
   python main.py
   ```

## Controls

- Left / Right: move
- Up / Down: accelerate / brake
- Esc: quit

## Objective

Stay alive, collect luxury gems, and build the highest score possible.
